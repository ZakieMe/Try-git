DOM Manipulation

Cara JavaScript "berbicara" dengan HTML kamu

DOM (Document Object Model) adalah representasi HTML sebagai pohon objek. Setiap tag HTML adalah satu node. JavaScript bisa masuk ke pohon ini dan mengubah apapun — teks, style, menambah, atau menghapus elemen.

Tiga operasi utama:

Pilih elemen — temukan tag HTML yang ingin diubah
Ubah konten/style — ganti teks, warna, atau class CSS
Buat/hapus elemen — tambah atau buang elemen dari halaman

Cara memilih elemen

// Pilih berdasarkan ID (paling spesifik) const judul = document.getElementById('judul'); // Pilih dengan CSS selector (paling fleksibel) const btn = document.querySelector('.btn-primary'); const inp = document.querySelector('input[type="text"]'); // Pilih SEMUA elemen yang cocok → NodeList (mirip array) const items = document.querySelectorAll('li'); items.forEach(item => console.log(item.textContent));

Ubah konten & style

// Ubah teks (lebih aman dari innerHTML) judul.textContent = 'Halo Dunia!'; // Ubah HTML di dalam elemen judul.innerHTML = '<em>Halo</em> Dunia!'; // Ubah style langsung judul.style.color = 'tomato'; judul.style.fontSize = '24px'; // Tambah/hapus/toggle class CSS — cara terbaik! judul.classList.add('aktif'); judul.classList.remove('aktif'); judul.classList.toggle('gelap'); // add jika tidak ada, remove jika ada

Dua contoh ini mewakili 80% pola DOM yang akan kamu temui di proyek nyata.

Dark mode toggle

Klik tombol → toggle class di body → CSS menangani visualnya.

// HTML: <button id="toggle">Mode Gelap</button> const btn = document.querySelector('#toggle'); btn.addEventListener('click', () => { document.body.classList.toggle('dark'); // Ubah teks tombol sesuai kondisi const gelap = document.body.classList.contains('dark'); btn.textContent = gelap ? 'Mode Terang' : 'Mode Gelap'; });

Daftar dinamis

Ambil nilai input → buat elemen baru → masukkan ke DOM.

// HTML: <input id="inp"> <button id="add"> <ul id="list"> document.querySelector('#add').addEventListener('click', () => { const input = document.querySelector('#inp'); const teks = input.value.trim(); if (!teks) return; // abaikan jika kosong const li = document.createElement('li'); // buat elemen baru li.textContent = teks; // isi kontennya document.querySelector('#list').appendChild(li); // masuk ke DOM input.value = ''; // reset input });

Bayangkan HTML sebagai denah rumah, dan DOM adalah versi digital denah itu yang bisa kamu ubah sambil rumahnya sudah dihuni. querySelector seperti menunjuk ruangan tertentu; classList.toggle seperti menyalakan/mematikan lampu ruangan itu; appendChild seperti menambah kursi baru ke ruang tamu tanpa membangun ulang rumahnya.

Kuncinya: DOM adalah representasi hidup. Begitu kamu mengubahnya lewat JavaScript, browser langsung menggambar ulang tampilan — tanpa reload halaman.

Coba kerjakan sendiri sebelum lihat mini project di tab berikutnya:

  1. Buat tombol yang saat diklik mengubah warna latar body secara acak.
  2. Buat input teks + tombol "Tambah" yang menambahkan item baru ke daftar `<ul>`.
  3. Buat setiap item di daftar bisa dihapus saat diklik dua kali.
