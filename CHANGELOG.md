# Changelog

Semua perubahan penting pada proyek ini dicatat di file ini.
Format mengikuti [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Fitur **GitHub Live Lookup**: pencarian statistik profil GitHub (repos, followers, following, total star) secara real-time lewat GitHub REST API.
- Navigasi burger menu untuk layar mobile.
- Halaman `Pelajaran_manipulasi_dom_js.html` kini terhubung penuh ke navigasi utama dan tombol CTA di `indeks.html`.
- Dukungan `prefers-reduced-motion` untuk aksesibilitas.

### Changed
- README diperbarui dengan struktur proyek dan badge yang sesuai dengan repo `Jouqio/Try-git`.
- Perbaikan `alt` text dan `aria-label` di beberapa elemen interaktif.

### Fixed
- Perbaikan kontras fokus keyboard (`:focus-visible`) di seluruh elemen interaktif.

## [0.2.0] — Dashboard

### Added
- Hero section dengan animasi partikel canvas.
- Grid achievement dengan filter (earned/progress/available/legacy).
- Timeline dan roadmap 5 fase.
- Dark/light mode dengan persistensi `localStorage`.

## [0.1.0] — Foundation

### Added
- Struktur repo awal, README, dan lisensi MIT.
